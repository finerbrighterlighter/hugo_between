{{- /* A colophon that exists only on paper. The site already had a print stylesheet that stripped the masthead, the footer and the spine, which is correct and which nobody ever sees twice. This fills the space it leaves. On screen it is `display: none`, so it is invisible to sighted readers and to assistive technology alike; it exists for the one person who prints a page and keeps it. The duck is the printer's mark. It is the site's own long-standing easter egg, hiding on the portrait, so it belongs here more than a generic asterism would. The identifying line is deliberately short. A paper's title is long by definition and is already the heading at the top of the sheet, so this names the journal instead, or the university where the page has no venue. No address: the browser already prints the URL in its own footer. Everything is a proper noun except one connective sentence, so it still reads correctly on a Burmese page whose translation is not yet written. */ -}} {{- $lastmod := .Lastmod -}} {{- if $lastmod.IsZero -}}{{- $lastmod = .Date -}}{{- end -}} {{- /* Short identifier: the journal, else the institution. */ -}} {{- $label := "" -}} {{- with .Params.venue -}}{{- $label = . -}}{{- end -}} {{- if not $label -}} {{- with .Params.institution -}} {{- with index site.Data.institutions . -}}{{- $label = .name -}}{{- end -}} {{- end -}} {{- end -}}
